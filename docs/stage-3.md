## 主要肌群标红

MuscleMap.vue使用本地原创SVG正面／背面人体示意图，根据动作primaryMuscle映射区域。
肌群名称也以文字显示，协同肌群不染成红色。胸部对应胸区、股四头肌对应大腿正面、腘绳肌对应大腿背面。
整体概念如活动度、心肺不伪装成某块肌肉。宽泛的背部、腿部标签对应多个区域。
位置参考基本解剖学命名：https://openstax.org/books/anatomy-and-physiology-2e/pages/11-2-naming-skeletal-muscles

这是一张简化位置示意，不表示激活比例或个体实际发力情况。
原有906张动作PNG保持原样；红色应用在独立人体图与目标标签上。
筛选栏的示意图表示所选筛选部位，详情页才表示该动作的主要目标。

## 核心文件

- src/stores/exercise.store.ts：集中处理加载状态、筛选、分页与详情查找。
- src/components/exercise/MuscleMap.vue 与 src/data/muscle-map.ts：人体形状和肌群映射。
- src/components/exercise/ExerciseFrames.vue：三帧展示与键盘交互。
- src/styles/tokens.css：颜色、间距、页面宽度；红色为 --color-target。
- src/styles/base.css：桌面与手机布局。
- docs/content-sources.md：第二阶段素材差异，仍然适用。

主数据通过动态import延迟加载，首页不下载整份目录；打开动作库或详情时加载。
生产构建的完整数据服务块约725kB（gzip约71kB），Vite会给出500kB的体积提示。该提示不影响构建，完整图鉴已与首页拆分。
图解素材约30MB，按需加载；全量离线下载在阶段6实现。

## 验收

启动项目：

```powershell
npm run dev
```

1. 打开动作库，确认显示302个动作，先展示12个，加载更多后增加12个。
2. 搜索“卧推”，器械选择“哑铃”，应剩3个动作。
3. 打开“哑铃卧推”，查看胸部红色标注；返回列表确认筛选仍在。
4. 打开“杠铃背蹲”，应标红大腿正面，后侧不误标为股四头肌。
5. 将浏览器调到手机宽度，点击图2或图3；键盘聚焦图解按钮后也能用左右方向键切换。
6. 查看“游泳”等已知差异条目，确认图解阅读提示可见；展开许可可查看来源。
7. 打开不存在的路由或动作ID，应显示可返回的错误页。
8. 今日和日程明确为演示，档案页说明下一阶段开放，不会假装生成真实计划。
